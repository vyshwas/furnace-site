THE TRI-STATE EVALUATION MATRIX

Three verdicts. Zero negotiations.

Most testing suites lie. They return a cheerful green pass because nothing crashed, even when the UI is completely unnavigable. Furnace enforces three uncompromising states: PASS, FAIL, and UNKNOWN. If an engine cannot definitively verify a condition, it is permanently quarantined as Unknown—never promoted to a false pass.

Deterministic Fixpoint Verification

Furnace detects target-size violations (<44px), semantic button misuse, and design token pollution. It generates a patch, compiles it, boots headless Chromium, and verifies that the bug is extinguished with zero introduced regressions.

EDITORIAL DOSSIER // TECHNICAL AUDIT

The five deadly illusions of AI-generated code.

LLMs are brilliant at producing syntax that compiles and disastrous at building interfaces that respect human sensory physiology and design system math.

[01 // PHANTOM GREEN]

The "It Runs" Hallucination

The code compiles, the dev server boots, and standard unit tests report green. But the interactive element rendered with 0px touch area and zero accessible name.

FURNACE COUNTER: Native Chromium CDP inspection measures rendered physical bounding boxes.
[02 // TOKEN DRIFT]

Arbitrary Style Pollution

Instead of adhering to strict design tokens, the AI invents arbitrary values like p-[13px] and bg-[#3a2f11], rotting your design system from within.

FURNACE COUNTER: Token sweep engine fails unmapped arbitrary classes and restores design tokens.
[03 // THE DIV TRAP]

The Semantic Void

Nested <div> elements styled to look like buttons, checkboxes, and tabs—completely invisible to screen readers and keyboard navigation.

FURNACE COUNTER: Inspects accessibility tree roles directly via CDP; enforces keyboard accessibility.
[04 // RECURSIVE ROT]

The Broken Auto-Fixer

Asking a coding model to fix its own bugs causes it to silently break two other components while claiming the task is complete.

FURNACE COUNTER: Monotonic fixpoint proofs rollback any patch that introduces new regressions.
[05 // FALSE CONFIDENCE]

The Unchecked Surface

Tools that guess when they cannot see. If a page requires authenticated cookies, standard tools either crash or falsely report zero violations.

FURNACE COUNTER: Strictly marks unreached pages as Unknown; writes them into the staging receipt.
