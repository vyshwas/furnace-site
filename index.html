Core Engineering

Headless Chromium Verification & Monotonic Fixpoint Proofs

Furnace operates beyond synthetic mocks. It compiles against genuine headless Chromium instances using Chrome DevTools Protocol (CDP), testing reality-bound visual regressions, DOM layout bounds, network intercept loops, and deterministic AST transformations.

Cryptographic Receipts
Every run generates a SHA-256 attested receipt sealing the verified artifact hash, execution telemetry, and CDP proof chain.
Monotonic Fixpoints
AST repair operations are mathematically bounded to terminate within n iterations without cyclic oscillations or regression traps.
Compliance Signals
Automated signal passes inspecting third-party font calls, tracking scripts before consent, and email unsubscribe routes.
