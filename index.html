FURNACE LABS v0.1.0-alpha.1

Ship AI-built software with evidence, not hope.

Furnace checks your pages, heals what it can prove, and hands you receipts. What it cannot prove, it marks unknown — never a pass.

mkdir furnace-alpha && cd furnace-alpha && curl -fsSL https://github.com/vyshwas/furnace-dist/releases/download/v0.1.0-alpha.1/furnace-v0.1.0-alpha.1.tgz | tar xz && ./install.sh

No sign-up. No backend. Node 24 required.

Unknown is a feature

Three verdicts, no bluffing. A finding without evidence is unknown, and unknowns ship in the report — never silently dropped, never upgraded to a pass.

✓ PASS

Original failure re-proven gone. No new findings. Merge-ready.

✕ FAIL

Patch incomplete or introduced a regression. Held for humans.

? UNKNOWN

Cannot be proven either way. Listed, routed, never merged.

From install to receipt in three commands

  1. Init inspects your repo. Framework, routes, and component dirs auto-detected; you answer only what cannot be known. Writes furnace.json.
    node furnace/bin/furnace.js init --workspace=.
  2. Run checks and heals. Four engines sweep; the fixer proposes; an independent verifier disposes — in a clean copy, never your files.
    node furnace/bin/furnace.js run --manifest=furnace.json --workspace=. --out=furnace-out
  3. Read the receipt. Staging report leads with proven-safe. Every repair carries intent, patch, verification, verdict.

What Furnace can prove today

  • realUI checks in headless Chrome: computed styles plus the CDP accessibility tree.
  • boundedGradient contrast across parsed stops; mixed gradients stay incomplete.
  • static-onlyaria-hidden and focus from DOM facts; JSX healing with file-level acceptance.
  • realAuth gates over HTTP; console errors and failed requests from live loads.
  • noisyLoad timing against explicit budgets.
  • estimatedQA-waste figures: arithmetic from stated assumptions, never measurement.
  • not-builtLLM agents, auto-created PRs, tenant isolation proofs.
