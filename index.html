01 // VERIFICATION GATES

The 8-Channel Launch Array

Static clearance criteria executed locally on your machine with zero source code sent to external servers.

[GATE-01] Secrets Entropy & AST

Detects production API tokens, private keys, and database credentials accidentally embedded in client bundles, commit artifacts, or unsafe environment fallbacks.

[GATE-02] Authentication Syntax Tree Trace

Parses the actual AST route execution paths across Express, Next.js, and Fastify to ensure every sensitive endpoint strictly enforces verified login sessions.

[GATE-03] Authorization Scope Boundary

Verifies object-level tenant boundaries. Guarantees that query filters enforce user ownership and prevent cross-tenant data leakage.

[GATE-04] Admin Boundary Privilege Proof

Flags administrative handlers, migration scripts, and maintenance tools accidentally exposed on public network surfaces without explicit role verification.

[GATE-05] Abuse Controls Cost & Rate Gate

Ensures that unauthenticated endpoints, SMS dispatchers, LLM inference routes, and file upload handlers carry deterministic rate limiters to prevent billing exhaustion.

[GATE-06] Server Trust Sink Tracing

Detects mass assignment vulnerabilities (e.g. passing unvalidated req.body directly into database schemas), SSRF sinks, and arbitrary URL redirects.

[GATE-07] Input Validation Schema Contract

Checks payload boundaries and type coercion. Verifies schema enforcement on incoming requests and guards against path traversal in file download endpoints.

[GATE-08] Launch Hygiene Protocol Audit

Audits CORS configuration, cookie security directives (HttpOnly, Secure, SameSite), security headers, and production sourcemap leakage.

02 // ARCHITECTURAL DIFFERENCE

Why Regex Scanners Produce Dangerous False Passes

Traditional linters match keywords. Furnace evaluates the execution graph of your syntax tree.

TRADITIONAL LINTER / REGEX SCANNER RESULT: FALSE PASS (DANGEROUS)

Standard pattern search inspects text keywords. If a route file contains a function named requireAuth, it assumes the endpoint is protected:

router.post('/api/delete-user', (req, res, next) => { // requireAuth is imported but never called here! database.users.delete(req.body.id); });

Because the keyword appears in the file, naive scanners mark this route as guarded. In production, unauthenticated attackers can delete arbitrary accounts.

FURNACE AST SEMANTIC ENGINE RESULT: FAIL (CATCHES BYPASS)

Furnace parses code with Babel into an Abstract Syntax Tree. It traces the actual execution graph of middleware callbacks and handler functions:

[FAIL] AUTHENTICATION // Route: POST /api/delete-user ↳ Handler astNode #124 references database.users.delete ↳ 0 authentication middleware nodes in execution chain ↳ Remedy: insert verifySession middleware before handler

Furnace does not care what functions are named. It only passes what it can prove executes before state mutations take place.

05 // QUESTIONS

Frequently Asked Questions

Plain answers about what Furnace checks, what it doesn't, and what it costs.

Is AI-generated code safe to launch?

Not by default. AI tools often produce apps that work but have common holes: routes with no login check, missing ownership checks so one user can edit another user's data, fallback secrets in code, and database tables with no access rules. Check before real users arrive.

How do I check if my Cursor or Lovable app is secure?

Run Furnace on the project folder. It reads the code and returns READY, NOT READY or NOT SURE YET, with each problem listed alongside a fix and a prompt you can paste into your AI coding tool.

Why not just ask Claude or ChatGPT to review my code?

An AI review can change between runs and can miss problems with full confidence. Furnace's check uses fixed rules and no AI model, so the same code always gets the same answer, and when it cannot read something it says NOT SURE instead of passing it.

Does Furnace send my code anywhere?

No. The code check runs on your own machine and sends nothing off it.

What does Furnace check?

Login and permission checks on every route, ownership checks on records, exposed secrets (including keys deleted from git history), database rules such as Supabase row rules, rate limits, and vulnerable dependencies.

Which systems and languages does Furnace support?

It reads JavaScript, TypeScript and Python projects. It is an early alpha, tested on Windows; Linux is not verified yet.

How much does Furnace cost?

The Launch Audit is $99 at the founding price (limited to 10), with your money back if there is nothing to fix. Furnace Pro is $19 per month.
