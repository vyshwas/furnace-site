The Tri-State Integrity Engine

Unknown is an explicit feature.

Three verdicts, zero bluffing. When visual contrast or assistive roles cannot be definitively verified, Furnace refuses to guess. A finding without proof is marked unknown — listed openly in the staging report, routed to humans, and never masqueraded as a pass.

✓ PASS VERDICT 01

Merge-Ready

Original failure re-verified gone. Zero introduced regressions. Patch passed file-level syntactic and fixpoint constraints. Safe to merge.

✕ FAIL VERDICT 02

Regression Held

A proposed healing patch left the failure intact or introduced new token pollution. Source code left pristine; repair rejected.

? UNKNOWN VERDICT 03

Human Discretion

State cannot be verified without credentials or human domain context. Documented in the receipt ledger, never upgraded to a pass.

Receipts specimen from pilot run on third-party Next.js application:

Operational Methodology

From initialization to receipt in three commands.

Furnace executes in an isolated sandbox, never editing your source files directly until a repair receipt has passed independent verification.

  1. 01

    Inspect & Calibrate

    Auto-detects framework (Next.js, React), page routes, component trees, and Tailwind configs. Prompts only for unprovable base URLs. Writes furnace.json.

    node furnace/bin/furnace.js init --workspace=.
  2. 02

    Execute & Heal

    Headless Chromium sweeps contrast, target size, and semantic roles via Chrome DevTools Protocol. The remediator proposes fixes in isolated temporary files.

    node furnace/bin/furnace.js run --manifest=furnace.json --workspace=. --out=furnace-out
  3. 03

    Audit the Receipts

    Staging reports lead with what is proven safe. Every repair carries the exact patch, intent contract, verification status, and cryptographic seal.

    cat furnace-out/staging-report.md

Furnace logs feedback to a local file on your machine (feedback.jsonl). Nothing is transmitted over the wire. If a run breaks, a prefilled GitHub issue URL is generated locally for you to review and submit manually.
